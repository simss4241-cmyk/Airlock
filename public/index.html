Settings

Each thread has its own read-only workspace. Switching threads switches file access with it.

Sent with every message. When an Oversight model is selected it crosses the boundary along with the conversation — so keep names, paths and anything private out of it.

Temperature and Top P apply to both tiers. Top K and Context are local only: num_ctx is Ollama's KV-cache budget and has no remote meaning, and top_k is not part of the OpenAI schema the remote tier speaks — neither is sent across the boundary.

Context trades speed for room. The KV cache competes with the model's own weights for VRAM, and once weights spill to system RAM generation slows sharply — so raise it when a task needs the room rather than by default. Muse Glimmer's recommended sampling is 1.0 / 0.95 / 64.
